Grass Project Announcement - August 25, 2026


GrassGFX Announcement and Technical Details

This document outlines the primary objectives, architectural structure, rollout schedule, and platform support scope of the GrassGFX project, which was announced on August 25, 2026.

1. Purpose and Rationale for the Development of the GrassGFX Project
GrassGFX is a next-generation library built upon the EFL (Enlightenment Foundation Libraries) framework that enables developers to create graphical interfaces. While the traditional EFL architecture requires a series of function calls and detailed configurations to create a basic interface element (widget), GrassGFX optimizes this process, allowing the same element to be created with a single function call.

2. Hybrid Architecture and Functional Design
One of the library's most fundamental advantages is the hybrid structural approach it adopts:
- Developers can build interface components individually using functions and a detailed control mechanism, if they wish.
- Alternatively, they can rapidly set up complex interface structures using a single function.
Furthermore, the function names used throughout the library have been designed with an intuitive structure to enhance the developer experience and accelerate the coding process.

3. Distribution Schedule and Early Access Process
The official source code release of the GrassGFX project is scheduled for September 17, 2026. Various user guides, documentation, and explanatory materials are being prepared for developers who wish to gain early access to the library and the project's source code prior to that date.

4. Platform Support Scope and Distribution Policy
-Current Support (Linux): Currently, only the Linux platform is officially supported.
-Future Plan (macOS, BSD and derivatives, Unix systems): In subsequent stages, it could be adapted for and distributed on other Unix-based and similar platforms.
-Not supported (Windows): In accordance with project policy, no distribution or port for the Microsoft Windows operating system will be produced.


Linux's 35th Anniversary - August 25, 2026


35th Anniversary of the Linux Kernel and Comprehensive History

This document has been prepared on the occasion of the 35th anniversary of the Linux kernel, based on Wikipedia data.

1. Background and Initial Steps
Linux kernel's story began in 1991 when Linus Benedict Torvalds, a computer science student at the University of Helsinki in Finland, set out with a personal need and curiosity. At that time, the Minix operating system, widely used in academic and commercial environments, had closed source codes, could not be modified, and contained educational license restrictions, which drove Torvalds to design his own operating system kernel from scratch.
Initially developed to directly learn and understand the protected mode features of the Intel 80386 microprocessor, this hobby project quickly evolved into a fully fledged kernel infrastructure compliant with POSIX standards.

2. Announcement of August 25, 1991 and the Name FreaX
Linus Torvalds announced his project to the world with his famous message sent to the comp.os.minix newsgroup on Usenet on August 25, 1991. The foundational step taken on this date is considered the dawn of today's massive open-source ecosystem.
Torvalds initially named the FTP server hosting the project's source code "FreaX," a combination of the words "Free" and "freak." However, Ari Lemmke, the administrator of the FTP server, did not like this name and changed the directory name on the server to "Linux" inspired by Linus's name, and the project officially began to be called by this name.

3. Integration with the GNU Project and the GPL License
Lacking its own compiler or system toolset in its early versions, the Linux kernel merged with free software components (GCC, bash, Coreutils, etc.) developed by the GNU Project led by Richard Stallman. The combination of GNU user space tools and the Linux kernel gave birth to a fully operational and free operating system ecosystem (GNU/Linux).
While the project was initially distributed under a restrictive non-commercial license, it was moved under the **GNU General Public License** (GPL) in 1992. This move enabled developers worldwide to freely modify, develop, and contribute to the code, accelerating the project's growth to an explosive pace.

4. Historical Chronology and Milestones
- August 25, 1991 (First Announcement): Proclamation of the project by Linus Torvalds in the comp.os.minix group.
- September 17, 1991 (Version 0.01): The first official release containing the kernel's source code was publicly published.
- 1992 (Transition to GPL License): The code was placed under GNU GPL and the first Linux distributions began to take shape.
- 1994 (Version 1.0): Full version released with a stable network stack and multitasking support; commercial distributions were born.
- 1996 (Version 2.0 and Mascot): Symmetric multiprocessing (SMP) support and Tux the penguin, designed by Larry Ewing, became the official mascot.
- 2003 (Enterprise Linux Era): Solutions like Red Hat Enterprise Linux and SUSE became standard in the enterprise server market.
- 2011 - Present (Modern Kernel Series): Global dominance in cloud computing, mobile systems (Android), and supercomputers.

5. Architectural Structure and Place in the Global Ecosystem
While Linux has a monolithic kernel architecture, it exhibits an extremely flexible structure thanks to dynamically loadable driver modules. Thanks to its Unix-like design, it delivers high performance, stability, and security.
Today, the Linux kernel serves as the backbone;
- In nearly all of the world's supercomputers,
- In billions of smartphones (on an Android-based infrastructure),
- In global cloud servers, web infrastructures, and embedded systems.
